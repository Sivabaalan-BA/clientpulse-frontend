# ClientPulse Frontend — React + TypeScript + Tailwind CSS

The frontend client for **ClientPulse**, an AI-powered client management and business workflow platform tailored for freelancers, agencies, and small businesses.

---

## 💻 Tech Stack
- **Framework**: React 18
- **Language**: TypeScript
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Data Visualizations**: Recharts
- **State & Context**: Zustand / Custom Auth & Toast Contexts
- **HTTP Client**: Axios with request interceptors

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The application runs on `http://localhost:5173` and opens in your default browser. When this workspace is opened in VS Code, its frontend development task starts automatically.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle is generated in `dist/`.

---
